# SchnarchenAde – Studio Redesign

Statische Website für Susanne Baumann.

## Technik
- HTML
- CSS
- Vanilla JavaScript
- Bootstrap 5.3.2 über CDN
- Google Fonts über CDN
- CSS-3D mit `perspective`, `transform-style`, `rotateX` / `rotateY`
- kleine Vanilla-JS-Parallax- und Tilt-Effekte
- kein Three.js
- kein GSAP
- kein Node.js / npm / Build-Step

## Hosting
Die vier Dateien können direkt auf einen normalen Webserver hochgeladen werden:
`index.html`, `style.css`, `script.js`, `README.md`.

Es ist kein Backend und kein Build-Prozess notwendig. Bootstrap und Google Fonts werden wie bisher über CDN geladen.
